# A&P — седмичен планер / личный недельный планировщик (PWA)

Приложение для телефона и компьютера. Основной язык болгарский, второй русский. Работает офлайн, ставится на главный экран.

## Что умеет

- Расписание Пн–Вс: добавить, изменить, удалить занятие; категории (можно добавлять свои кнопкой **+**); длительность считается сама.
- **Галочка у каждой задачи** и тонкая полоса прогресса внизу («Изпълнени 12 от 27»).
- **PIN-код при открытии** (по умолчанию 1234), смена PIN (старый, новый, подтверждение), блокировка кнопкой с замком и автоматически после 5 минут в фоне.
- Недели и архив: «Приключи седмицата» → архив только для просмотра (со статистикой и выполненными задачами) → «Създай нова седмица».
- **PDF**: кнопка «Свали PDF» делает чистый лист А4 (неделя, итоги, задачи по дням с галочками).
- Резервная копия в файл и восстановление из файла.
- **Вход через Google и синхронизация между устройствами** (нужна разовая настройка, см. ниже).
- Светлая и тёмная тема.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите **содержимое** папки (не ZIP) в корень, включая `.nojekyll` и папку `icons`.
2. Settings → Pages → Deploy from a branch → `main`, `/ (root)` → Save.
3. Откройте `https://ваш-логин.github.io/название-репозитория/`.
4. Android (Chrome): меню ⋮ → «Установить приложение». iPhone (Safari): «Поделиться» → «На экран “Домой”».

При обновлении файлов в репозитории закройте и снова откройте приложение. Если видите старую версию, поменяйте `CACHE` в `sw.js` (например, `ap-planner-v3.0.1`).

## Вход через Google и синхронизация (Firebase)

Сайт на GitHub Pages не имеет своего сервера, поэтому аккаунты и облако даёт бесплатный сервис Google Firebase. Настройка занимает около 10 минут и делается один раз. Пока ключи не вставлены, приложение работает только локально, а в разделе «Още» вы увидите подсказку.

1. Откройте https://console.firebase.google.com → **Add project** (Google Analytics можно отключить).
2. **Build → Authentication → Get started → Sign-in method → Google → Enable** → выберите свою почту Gmail → Save.
3. **Authentication → Settings → Authorized domains → Add domain**: `ваш-логин.github.io`.
4. **Build → Firestore Database → Create database** (режим production, любой ближайший регион).
5. Вкладка **Rules** в Firestore, вставьте и нажмите Publish:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
   Так каждый пользователь видит только свои данные.
6. **Project settings (шестерёнка) → Your apps → Web (</>)** → зарегистрируйте приложение → скопируйте `firebaseConfig`.
7. Откройте `firebase-config.js` и замените `null` на ваш объект:
   ```js
   window.AP_FIREBASE_CONFIG = {
     apiKey: "...", authDomain: "ваш-проект.firebaseapp.com",
     projectId: "ваш-проект", appId: "..."
   };
   ```
   (`apiKey` в веб-приложении не секрет, доступ защищают правила из шага 5.)
8. Загрузите изменённый файл на GitHub. В приложении: **Още → Вход с Google**. На втором устройстве сделайте то же самое с той же почтой.

Как работает синхронизация:
- Синхронизируются активная неделя, архив и свои категории. PIN-код, язык и тема остаются на каждом устройстве.
- Архивные недели с разных устройств объединяются. Активная неделя берётся из более свежей версии. Новое устройство с нетронутым начальным расписанием не затирает облако.
- Без интернета приложение работает, изменения уйдут в облако, когда сеть появится.
- Если окно входа блокируется браузером, разрешите всплывающие окна для сайта.
- Облако не заменяет резервную копию: изредка скачивайте файл.

## Хранение данных и ограничения

- Локально данные лежат в браузере устройства (IndexedDB + запасная копия в localStorage).
- Без входа через Google устройства не синхронизируются. Переносить данные можно файлом копии.
- Очистка данных сайта или удаление приложения стирает локальные данные. Спасают облако и копии.
- Приложение с главного экрана и тот же сайт во вкладке (особенно на iPhone) могут хранить данные раздельно.
- PIN защищает только от случайного открытия и не шифрует данные. Забыли PIN: очистите данные сайта (PIN станет 1234), потом восстановите данные из облака или копии.
- Данные в Firestore не шифруются на вашей стороне: их видите вы как владелец проекта Firebase.

## Установка как настоящей программы

Сначала выложите файлы на GitHub Pages (шаги выше) — адрес вида `https://ИМЯ.github.io/РЕПО/`.

**Android (телефон):** откройте адрес в Chrome → меню ⋮ → «Установить приложение». Появится значок A&P, приложение открывается без адресной строки, работает офлайн (это полноценное установленное приложение / WebAPK).
Если нужен именно файл `.apk`: на сайте https://www.pwabuilder.com вставьте адрес → «Package for stores» → Android. (Нужен публичный адрес; собирается на их стороне.)

**Windows:** откройте адрес в Edge или Chrome → значок установки в адресной строке (или меню → «Приложения» → «Установить этот сайт как приложение»). Приложение появится в меню «Пуск» и на панели задач.

**Windows `.exe` (необязательно, не проверено в этой среде):** папка `native/` + `.github/workflows/windows-installer.yml`. В GitHub: Actions → «Windows installer (.exe)» → Run workflow → скачайте `AP-Planner-Windows-Setup`. Вход через Google в такой версии не работает (Google запрещает вход во встроенных окнах) — используйте установку через Edge/Chrome, если нужна синхронизация.

**iPhone:** Safari → «Поделиться» → «На экран Домой».
